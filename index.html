M3P-R1 produces solver-grounded plans across heterogeneous robotic modalities and their compositions.

Overview

From language to solver-grounded motion plans

Multi-modal motion planning requires a robot to reason jointly about continuous motion and discrete mode transitions: a biped may walk to an object, an arm may reach through clutter, and a team of aerial robots may coordinate a rendezvous. These tightly coupled geometric and symbolic decisions are difficult to model with a single planning abstraction.

M3P-R1 turns natural-language task descriptions into executable mixed-integer programming (MIP) code. Rather than asking an LLM to output an unverified answer, our approach generates solver-backed Python programs whose variables, constraints, and objectives can be executed and checked.

LLM + MIP

During reinforcement fine-tuning, the solver provides verifiable feedback on format, API usage, program execution, and task correctness. The result is a planning policy that learns reusable discretization primitives and composes them into multi-modal programs.

Task coverage

One pipeline, diverse robotic tasks

The M3P-R1 pipeline is built around modality-level MIP primitives, then learns to combine them with cross-modal constraints such as shared meeting points, contact locations, reachability, and synchronized intermediate states.

01

UAV navigation

Collision-free trajectories through structured obstacle maps.

02

Inverse kinematics

Obstacle-aware arm motion that satisfies kinematic constraints.

03

Footstep planning

Discrete contact placement coupled with continuous locomotion.

04

Contact selection and geometry-aware object interaction.

05

Discrete contact choices for dexterous, geometry-aware manipulation.

06

Multi-modal composition

Joint programs that coordinate navigation, locomotion, manipulation, and aerial agents.

Method

Learning to compose MIP programs

M3P-R1 starts with supervised fine-tuning on executable MIP programs, then uses reinforcement fine-tuning with solver-verifiable rewards to improve code quality and planning correctness.

01

Describe

A natural-language task specifies the environment, constraints, and desired goal.

02

Generate

The LLM writes CVXPY-based MIP code using callable discretization APIs.

03

Verify

A MIP solver executes the program and returns objective feedback for training.

04

Plan

The resulting solution yields feasible, coordinated multi-modal trajectories.

Evaluation

Reliable planning across modalities

Solver-grounded generation improves task success

On LLMM3P Bench, M3P-R1 reaches 91.7% success on single-modal tasks and 80.9% on multi-modal compositions. The strongest prompt-only baseline reported in the paper reaches 65.3% and 40.3%, respectively.

  • Five single-modal task families
  • Eight multi-modal compositions
  • Joint discrete-continuous optimization
  • Trajectory validity checked by the solver
